      # § 7

      1. Опыт с краской: разбавляешь — вода всё равно окрашена → значит, краска из мельчайших частиц. Плюс тепловое расширение.

      2. Опыт с краской; масляная плёнка толщиной \~10⁻⁹ м.

      3. При нагревании промежутки между частицами растут → объём увеличивается.

      4. Жидкость в сосуде при нагревании поднимается. Вывод: жидкости расширяются. Причина — промежутки между частицами растут.

      5. Нет. Между частицами есть промежутки.

      Упр. 1. Промежутки между частицами ртути увеличились.

      Упр. 2. \~25 веков. Не было приборов, чтобы увидеть атомы.

      # § 8

      1. Мельчайшая частица вещества, состоит из атомов. У каждого вещества свой тип молекул.

      2. Из двух атомов водорода.

      3. Да. Молекула водорода делится на атомы.

      Упражнение 2

      1. d = V/S = 3·10⁻¹² / 3·10⁻² = 10⁻¹⁰ м

      2. Плёнка не тоньше одной молекулы.

      3. Между атомами свинца есть промежутки — они сжимаются.

      4. t = 2,7·10¹⁹ / 10⁶ = 2,7·10¹³ с ≈ 857 000 лет

      # § 9

      1. Мелкая твёрдая частица в жидкости, движется ударами молекул.

      2. Беспорядочное движение таких частиц.

      3. Удары молекул с разных сторон неодинаковы.

      4. Чаинки слишком крупные — удары уравновешиваются.

      Задание 7

      Это броуновское движение. При нагреве молекулы движутся быстрее → частицы краски двигаются интенсивнее.
